# 全屋智能门店：从残缺线索到客户交付

这里的“新客户接入”是门店的客户旅程。老板首次配置系统见[AI工作台接入](AI-WORKBENCH.md)，门店日常使用见[店长指南](01-门店店长使用指南.md)。

## 第一阶段：先接住线索，不要求一开始填满

来自设计师、装修公司、物业、异业合作、转介绍、到店与线上内容的线索，至少保留称呼/姓氏、已有联系引用或楼盘信息之一，意向可以已知或待问。比如合作设计师提供“王先生，想了解三室住宅的灯光方案”；这些是起点，缺全名、手机、预算都能继续列为待补。只有匿名需求主题而没有任何可识别信息时，先作为渠道准备资料，不能据此建立确定客户。

录入时保存渠道、合作来源、记录依据和已知需求。客户授权未知时保持未知，线索转交不自动获得咨询、预约、营销和售后的全部授权。原始电话、微信账号和家庭地址留在受控隐私存储，业务记录只保存引用与经允许的描述。

**这一阶段交付**：能追到来源的线索、已知信息和未知字段。**不能当成结果**：有效客户、已获营销同意、已到店。

## 第二阶段：逐步补信息，形成客户资料

线索完善员根据当前资料准备澄清问题，销售人员在授权范围内与客户核对：

| 信息 | 为什么要问 | 没问到时怎样处理 |
| --- | --- | --- |
| 称呼与身份引用 | 防止设计师、顾问和工程认错同一客户 | 保留原称呼，标记待核对，不编姓名 |
| 楼盘、空间与服务区域 | 判断能否服务，准备空间问题 | 仅记录已知楼盘或区域，不猜家庭地址 |
| 装修进度 | 决定布线、替换、安装和进场时机 | 保持未知；不按新房或已装修默认下方案 |
| 预算和优先需求 | 区分先解决灯光、窗帘还是全屋体验 | 预算未知不等于零购买力，不编金额 |
| 联系和用途授权 | 明确咨询、预约、营销、售后范围 | 未授权用途保持待办，撤回后停止相应推进 |
| 需求来源与确认记录 | 让后续顾问知道是客户陈述还是推测 | 猜测写为假设，客户确认后形成新版本 |

逐次完善已有线索，不用重复创建“新客户”掩盖历史。新字段带来源，冲突信息交给人核对；资料变更会生成新版本，后续任务使用当前版本。客户档案承接线索和需求，联系引用仍由受控存储管理。

**这一阶段交付**：可交接的客户资料、需求摘要和剩余问题。信息不足的资格判断会保留 `needs-information`，不能用一个完成任务的状态推断客户已成熟。

## 第三阶段：到店体验与销售准备

取得相应用途授权后，预约协调员拟定时间和路线，销售助理整理接待简报。门店按客户关心的生活场景体验：回家、观影、起夜、离家；结合中控、灯光、窗帘和传感产品讲条件与差异。

拟议计划与客户确认分开。系统不会自动发微信，也不会把“已生成话术”说成“客户已收到”。人类联系和客户确认都需要对应记录。AI 陪练可先练习“已经装修能否安装”“断网时哪些功能还可用”“为什么需要勘测”等异议，回答必须使用来源资料，不能保证所有设备互通。

**这一阶段交付**：拟议预约、体验路线、接待话术和客户确认依据。实际到店、满意度和成交需相应真实记录，当前演练不能提供真实经营业绩。

## 第四阶段：勘测、点位与设计

现场人员核对户型、房间、电路、零线、负载、网络、安装位置、施工时机和隐私要求。客户档案连接现场勘测；点位图记录空间尺寸和设备坐标，设计方案引用点位、BOM与场景。

点位和尺寸是记录中的设计输入，软件图形不代表真实竣工图或专业人员已复核。市电设备需要已勘测回路和厂家安装要求。精确型号、固件与兼容证据必须当前有效；同协议、同品牌或“支持Matter”不能替代精确组合依据。

**这一阶段交付**：有来源的勘测、可追到房间与设备的点位、设计说明、场景与BOM、排除项。缺条件先补证据或改方案，不能靠AI补零线、尺寸或电压。

## 第五阶段：报价、施工方案与合同

报价复算设备、施工和服务的成本与售价、折扣、毛利和期限。施工方案说明工序、依赖、人员、材料、安全核对和变更处理。合同连接客户、方案、报价与约定范围，店主审核当前内容摘要；签约事实需要人类提供客户证据。

报价草案不是已经发给客户的价格，合同草案不是已签合同。模拟导入的历史状态有明确来源和“未真实人审”标识，不能拿它当作实际店主批准或客户签字。正式门店要使用真实证据，合同文本还应由有资格的人完成业务与法律审查。

**这一阶段交付**：可核对的价格与范围、待审合同与施工准备；未获批准、过期、内容改变、财务红线违规都不能继续承诺。

## 第六阶段：采购、安装、调试、验收

采购按批准BOM核对数量、版本、到货与序列引用。完整备货之后才能登记安装里程碑；安装记录需要专业人员引用和安全核对。调试覆盖每个批准场景，失败就保留失败与修复任务。

客户验收同时检查客户接受、培训完成、控制权交接和零未闭问题。有记录的本地验收仍是人类提供证据，系统没有自行到现场验证。材料采购记录也不代表供应商已下单或钱已付款。

**这一阶段交付**：采购、安装、调试、客户培训与验收证据，以及保修/售后移交信息。缺任何前置就留在对应待办，不提前关闭项目。

## 第七阶段：售后与转介绍

设备离线、场景异常、网络、培训、安全和隐私问题按责任与严重程度分流。售后数字员工准备故障假设和处理计划，专业人员实施，客户确认后登记解决并安排回访。安全与隐私问题需要升级，不给客户危险的带电拆装指引。

转介绍与后续营销仍使用明确用途授权，交付完成不能自动扩大联系范围。经营复盘使用当前账本口径，把本地完成、客户提供、外部核验和模拟背景分清楚。

## 三条可复演的客户路线

1. **设计师残缺线索**：来源记录 → 澄清问题 → 逐次完善 → 客户资料 → 拟议体验 → 顾问接续。
2. **装修中方案客户**：授权与勘测 → 点位 → 设计/BOM → 报价审批 → 施工方案/合同 → 工程证据。
3. **交付后售后客户**：项目与场景 → 故障分级 → 处置准备 → 人类服务/客户确认 → 回访与复盘。
